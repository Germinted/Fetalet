Documentation

Model Architecture

FETALET uses a dual-branch neural network combining CNN-based feature extraction with prototype-based shapelet matching. The CNN branch extracts general temporal features from FHR and TOCO signals, while the prototype branch matches learnable shapelet patterns against candidate segments generated from the input.

Signal Format

FHRA Dataset: CSV files with columns for timestamp, FHR (fetal heart rate in bpm), TOCO (tocodynamometer/uterine activity), and label. Signals are processed using sliding windows with configurable stride for real-time analysis.

Performance Metrics

The model achieves 94.7% accuracy with 0.91 ROC-AUC on the test set. Average inference time is 12ms per sample, making it suitable for real-time fetal monitoring applications.
